# Proma v0.17.55 更新

## 新功能

- **DeepSeek V4 Flash 原生视觉** — 新增 `deepseek-v4-flash-vision-exp` 模型候选，并让 `deepseek-v4-flash` 在本地目录声明前即被识别为支持图片输入；DeepSeek 渠道开启视觉模型后可直接发送图片，不再因上游目录缺失而误判为不支持，实际模型 ID、协议与推理参数保持不变。
- **UISFX 通知音效库** — 引入 CC0 的 UISFX 音效与插图资产，提供紧凑的场景化音效选择、语义化通知提示音，并兼容旧的音效 ID；新配置不受影响，旧配置可平滑迁移，来源已注明署名。
- **协作委派等待时间延长** — 协作子会话默认等待时间从 30 分钟提升至 60 分钟，最大等待上限提升至 2 小时，长耗时的并行探索或审查任务不再因默认超时被过早打断。
- **浏览器 Google 超时自动回退 Bing** — 默认 Google 新标签页或搜索页在 3 秒内未完成加载时，自动停止旧导航并在同一标签页切换 Bing；国内网络环境下搜索入口不再长时间卡在空白等待。
- **通义千问改用 OpenAI 兼容端点** — 默认 DashScope Anthropic 兼容端点的通义千问渠道自动迁移到 OpenAI 兼容端点，配置版本升级至 v5；自定义 Anthropic 端点不自动迁移，避免改变用户明确配置的请求协议。
- **Agent 进度更新引导增强** — 优化 Agent 提示词中的进度更新引导，让长任务运行时更频繁、更清晰地向用户汇报可感知的阶段进展。

## Bug 修复

- **OpenCode 渠道按模型目录协议路由** — 同一 OpenCode Go 渠道可能提供多种协议，现在以模型目录声明为准选择请求协议，未命中目录时保留历史 OpenAI Chat Completions 默认值，避免推理档位与请求协议不匹配。
- **飞书支持 Lark 国际域名** — 每个飞书机器人可选择飞书 / Lark 域名，WebSocket、REST 与连接测试保持一致；二维码注册时可自动识别域名，存量国内飞书配置保持默认不变。
- **火山方舟 Coding Plan 模型清单修正** — Coding Plan 的 `/models` 返回方舟通用目录、不等同于套餐授权，改用套餐支持清单（含 Doubao Seed 2.1 Turbo、GLM-5.3、DeepSeek V4 系列等）作为渠道模型列表，不再把未授权模型当成可用项。
- **AskUserQuestion 等待更从容** — 仅针对 `AskUserQuestion` 这类用户主导的自由文本交互，把跨进程等待时间从 2 分钟延长到 15 分钟，其他能力调用的故障检测保持原样，用户可从容输入而不被中断。
- **关闭 MCP 编辑器后刷新测试状态** — 关闭 MCP 服务配置编辑器后自动刷新测试状态，不再停留在旧的连接结果。
- **浏览器允许内部 HTTPS 证书** — 受管浏览器放行内部自签名 HTTPS 证书，访问内网服务时不再被证书校验拦截。
- **编辑器返回后恢复自动化列表** — 从自动化表单返回侧边栏时恢复定时任务列表的显示状态，不再出现列表丢失或闪烁。
- **恢复屏幕外窗口边界** — 主窗口与计划窗口在恢复到已不可见的屏幕外边界时自动归一化到当前工作区，避免窗口被移出屏幕外后无法找回。
- **保留 Claude 自适应思考** — 重新注册非 OAuth 渠道为临时 Pi 提供方时，仅保留协议安全的 `forceAdaptiveThinking` 标记，当前 Claude 模型继续使用自适应思考，同时不泄露其他协议无关的工具 / 采样行为。
- **移除会话工作区不匹配拒绝** — 不再因会话归属的工作区与请求不一致而拒绝请求，改为保留启动槽位与工作区所有权，避免会话迁移改变已接受请求的项目归属；飞书镜像卡片等外部触发场景下请求更稳定。
