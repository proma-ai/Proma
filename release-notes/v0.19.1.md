# Proma v0.19.1 更新

## 新功能

- **Obsidian Vault 集成** — 会话侧边栏新增 Obsidian 笔记工作区：可切换 Vault、按文件树浏览与管理笔记，支持新建/重命名/删除笔记与文件夹。编辑器基于 LiveMarkdown 实时内核，渲染双链引用 chip、Properties 与代码块高亮，笔记自动保存；原 Scratch Pad 自动迁移进托管 Vault，聊天侧边栏与 Agent 上下文也能感知 Obsidian 笔记。
- **LiveMarkdown 覆盖项目记忆** — 项目记忆、自动化任务 prompt 等 Markdown 场景统一切换为 LiveMarkdown 实时编辑/预览内核，与 Vault 共享代码块渲染和剪贴板行为，代码高亮对齐 Shiki。
- **Office 文件高保真预览** — 为 DOCX、XLSX、PPTX 打包 OfficeCLI，在子进程中渲染高保真 HTML 预览并以 iframe 隔离展示；构建时校验并固定平台对应的 OfficeCLI 资源，原有渲染器保留为兜底。
- **MCP 与 CLI 连接目录** — 新增统一连接目录，内置常用服务提供商条目与本地品牌图标，支持安全凭证流与 OAuth 管道；同时完善手动设置提示，让 MCP 服务器接入更直观。
- **MCP 与 Skills 侧边栏入口整合** — 将 MCP 与 Skills 的管理入口收敛到统一的侧边栏访问路径，离开详情页时自动落盘变更。
- **右侧工作区双 Pane 并排查看** — Agent 右侧工作区支持双 Pane 并排查看，窄栏下自动切换单列布局，折叠侧边栏后仍可完整展开。
- **从目录直接打开终端** — 项目文件夹与改动面板目录支持一键在嵌入式终端打开；附加目录根及其子目录也提供终端入口，并以对应目录作为工作目录打开；Agent 运行时复用可见终端，减少无谓的终端堆积。
- **更新提醒增强** — 更新下载过期后自动刷新，并按期重复提醒用户处理更新。
- **适配 GLM-5.3-Flash 推理深度** — 模型注册与渠道管理中适配 GLM-5.3-Flash 的推理深度档位，上下文窗口计算与 reasoning profile 同步更新，设置页渠道表单可选对应深度。

## Bug 修复

- **修复无关文件预览被刷新** — 预览只针对目标文件刷新，隔离刷新边界并跟踪解析后的预览路径，避免查看一个文件时其它预览被连带刷新。
- **恢复 Git diff 汇总统计** — 改动面板恢复 Git diff 的汇总统计信息，变更概览不再丢失。
- **修复折叠侧边栏的会话访问** — 侧边栏折叠为窄栏时优先保留会话入口与工具状态提示，折叠后仍能快速回到会话。
- **保持目录状态与滚动位置** — 文件目录的展开/折叠状态与滚动位置跨切换保持，不再每次回到根目录。
- **修复终端光标跳动与输出裁剪** — 终端输出不再出现光标跳位或被裁剪，长输出展示更稳定。
- **Agent 流路由跨运行交接保留** — Agent 运行交接时保留流路由，后台刷新与终态事件不再错乱。
- **允许用户关闭 Agent 浏览器标签** — Agent 打开的浏览器标签支持手动关闭，不再只能等 Agent 自己清理。
- **受管浏览器 favicon 渲染** — 受管浏览器标签页正确渲染站点 favicon。
- **禁用系统刷新快捷键** — 屏蔽系统级刷新快捷键，避免误触打断当前操作。
- **修复设置返回悬停布局偏移** — 设置页返回按钮悬停不再引起布局跳动。
- **修复窄右侧面板缩放** — 窄右栏折叠/展开时面板尺寸与单列布局稳定，不再异常挤压。
- **改动页不再自动跳转** — 移除改动页自动跳转行为，保留变更数据刷新与未读指示，避免后台变更打断当前操作。
- **Skills 面板 prompt 立即同步** — 设置项改动后设置 prompt 立即填入当前会话，不再需要刷新。
- **MCP 配置写入安全加固** — 完整配置写入、显式禁用、OAuth 代理、凭证绑定端点等环节补齐校验；远程 transport 统一走应用代理并安全释放，防止挂起与误启。
- **连接目录顺序与条目修正** — MCP 连接目录按优先级稳定排序，移除 Playwright 等无效条目。
- **委派结果强制收敛** — 协作子 Agent 必须收敛结果后才能继续主线，防止把未完成的任务当作已交付。
