# Proma v0.19.52 更新

## 新功能

- **MCP 一键登录** — 支持 OAuth 的服务（如 GitHub）点「授权」就会打开浏览器登录，不用手动填 Token。
- **Copilot 额度可见** — 能看到剩余用量和重置时间。
- **新增 DeepSeek V4.1 Flash** — 可单独设置思考深度。

## 体验优化

- **表格长文本更好编辑** — Markdown 表格输入长内容会自动换行，不用横向拖动。
- **左栏更整齐** — 重排图标与间距，项目行和会话行对齐。
- **模型名称完整显示** — 模型列表会按窗口宽度自动加宽，长名称不再被截断。

## Bug 修复

- **关闭 Skill 不再误报** — 关闭时提示「已关闭」，不再显示成「已移除」。
- **`~` 路径和本地图片可用** — `~/xxx` 引用的文件和图片能正常打开，读取失败时会给出提示。

- **Linux AppImage** — `Proma-0.19.52.AppImage`
- **Linux deb** — `proma_0.19.52_amd64.deb`
