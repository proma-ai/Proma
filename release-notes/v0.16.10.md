# Proma v0.16.10 更新

## 新功能

- **macOS 日历（EventKit）双向同步** — 规划（Planning）事项可一键同步到 macOS 日历与提醒事项，Proma 中创建、完成或调整的事项会实时反映到系统日历；反向同步外部 EventKit 集合的变更回 Proma，两端保持一致。同步冲突需要明确选择保留哪一侧，外部删除也会安全地回写，保证数据不出错。
- **原生品牌启动闪屏** — 应用启动时显示品牌化原生闪屏，替代原有空白加载期；渲染进程异常时可回退到加载界面，启动过程更连贯、稳定。
- **规划快捷入口** — 通过全局快捷键或系统托盘即可快速创建规划项，无需打开主界面也能随手记录待办；保留本地 fallback，快捷键被占用时依然可用。
- **新手引导可重放** — 设置页新增「重放新手引导」入口，随时可重新观看首次启动的引导流程；首个引导页新增向下滚动提示箭头与「继续向下滚动，查看这一步的真实示例」文字行，新用户不会错过下方内容。
- **侧边栏恢复「新建会话 + 搜索」并排按钮** — 展开态与折叠态都恢复「新建会话 + 搜索」相邻布局，高频操作更快触达；侧边栏分组标题字号统一为 13px，层级更清晰。
- **Todo 列表层级可读性增强** — 加重 Todo 页分割线与边框，分组之间更易区分。

## Bug 修复

- **长草稿光标跳转修复** — 修复在较长草稿中输入时光标跳转的问题，长文本编辑体验更稳定。
- **Git 变更监控刷新循环修复** — 修复 git-diff watcher 的刷新循环，限制远端基线刷新频率并去重共享 worktree 抓取，避免无谓的重复扫描与卡顿。
- **Agent 会话列表刷新优化** — 避免 Agent 变更时触发完整会话列表刷新，降低不必要的 UI 更新开销。
- **Agent 灵动岛适配完善** — 移除非原生 fallback 渲染表面；修复紧凑布局响应式问题，停止后正确清除运行状态，各平台表现一致。
- **DeepSeek V4 Pi 推理力度映射** — 为 DeepSeek V4 Pi 模型正确映射推理力度（reasoning effort）请求参数，设置项与实际请求一致。
