# Proma v0.17.42 更新

## 新功能

- **系统性能大幅提升** — 本次更新的核心：对 Agent 渲染、流式输出与长会话状态管理做系统性优化，长时间使用、长会话与多会话并行时整体明显更流畅。流式输出不再每帧全量重新解析 Markdown，改为分块记忆化渲染，代码高亮结果按语言缓存复用、流式期间跳过语言自动检测，避免拖垮渲染主线程；定位并修复长会话累积性卡顿（单 Agent 运行 20 分钟后输入按键排队延迟从 38ms 升到 185ms 的问题已解决）：批量复制 delta、索引解析缓存、后台会话运行态回收、消息批量追写、按会话直读流式状态等多处高成本路径被重写；多会话同时流式输出时后台流自动降级、输入区与用量更新完全隔离，不再互相抢占；侧栏归档会话改为懒加载、浏览器与面板渲染抖动降低、窗口后台节流恢复——会话越多、运行越久，提升越明显。
- **Pi 运行时升级并迁移至独立进程** — Agent 运行时升级至 Pi 0.84.2 并托管到独立 Electron 工具进程（命名为 Proma Runtime），与主界面隔离，可在系统监控中清晰识别与诊断；Agent 运行更稳定，单点故障不会拖垮整个应用。
- **新增 GLM-5.3 与 Doubao Seed 2.1 模型预设** — 智谱 API、OpenCode Go 与火山方舟 Coding Plan 渠道新增 GLM-5.3 预设（1M 上下文、官方 thinking 开关，Anthropic / OpenAI 双协议正确发送）；火山方舟 Coding Plan 同步补齐 Doubao Seed 2.1 Pro / Turbo（256K 上下文）。
- **受管浏览器跨标签跟随并可关闭** — 浏览器可跨标签持续追踪 Agent 的操作进度，切换标签不丢上下文；Agent 可主动关闭受管浏览器（需要用户批准），不再强制常驻。
- **会话切换动画与流式输出平滑** — 切换 Agent 会话与历史记录带轻量过渡动画（遵循系统"减少动态效果"设置），标签切换延迟已移除、实时消息立即呈现；流式输出跟随更稳定，工具结果保持实时。
- **规划工作流精简与提示词澄清恢复** — Todo 规划流程更顺畅，恢复 prompt-clarifier 等 Skills，需求模糊时自动引导澄清，减少来回返工。

## Bug 修复

- **渲染进程崩溃可自动恢复** — 主界面渲染进程崩溃后会自动重启并恢复，恢复失败时提供带崩溃诊断信息的兜底页面，不再白屏卡死。
- **会话标题自动重命名修复** — 修复标题自动重命名失败的问题；自定义渠道标题生成失败时回退到兜底重命名，不再出现空标题或失败提示。
- **Agent 工具调用显示完善** — 工具调用行与描述对齐、隐藏冗余标签，Read 摘要更紧凑，工具控件布局更稳定。
- **历史模型身份与消息通道保持正确** — 流式输出、空响应与错误消息都会保留运行时渠道身份，历史会话中同名模型、重复模型 ID 的别名与提供商解析不再串线。
- **Agent 运行稳定性修复** — 等待 AskUserQuestion 用户回复再继续、排队消息状态稳定、语音输入重启前正确重置生命周期、文件面板状态与会话隔离、窗口后台节流恢复。
- **浏览器导航与面板体验修复** — 允许私网地址导航与下载请求，修复会话切换时残留陈旧视图、面板渲染抖动与滚动条宽度失调。
- **消息渲染与交互细节修复** — 修复发送消息时屏幕闪烁、思考块闪烁、空思考块过早渲染、历史引用弹窗抖动、输入框焦点被抢、后台标签重复排队用户消息、委派子会话消息与侧栏重复、刷新后消息未显示、侧边栏 tooltip 不自动消失、固定会话图标误显示等问题。
