# Proma v0.17.26 更新

## 新功能

- **Agent 链接在受管浏览器中直接打开** — Agent 回复中的网页链接现在可直接交给内置受管浏览器打开，无需跳出 Proma；不同 Agent 会话的浏览器标签保持隔离，便于在同一工作流中继续浏览、搜索与操作页面。
- **定时任务支持工作日与每日执行窗口** — 固定间隔任务可设置仅在工作日、周末或自定义星期运行，并限定每天的有效时段；日历会同步展示任务的实际活跃窗口，例行检查、工作时段自动化等场景更易配置与核对。
- **会话搜索支持更准确的模糊匹配** — 搜索会规范处理中英文标点、大小写与常见分隔符，并支持连续片段及轻微输入误差；结果按匹配质量排序、优先展示用户消息，查找历史对话更快更准。
- **Windows Agent 状态通知与托盘交互** — Windows 现可在 Agent 完成、报错或需要权限/计划审批时通过系统通知和托盘状态提醒；悬浮托盘图标可查看会话详情，重要待处理状态更容易被发现。
- **新增 Qwen3.7 Flash 渠道预设** — 渠道设置中可直接选择 Qwen3.7 Flash，减少手动填写模型标识的步骤。

## Bug 修复

- **受管浏览器导航与下载体验完善** — 浏览器现在可正常处理页面打开的 popup 与下载请求，避免被错误拦截；同时修复受限 URL 导航、迟到的旧标签导航事件，以及方向键、翻页键等无法触发页面默认滚动的问题。
- **语音输入初始化更稳定** — 修复首次授权麦克风后录音捕获状态未正确恢复的问题；语音听写会等待捕获链路就绪再进入可用状态，减少点击后无响应或过早开始的情况。
- **Agent 输入与消息队列体验优化** — 修复输入框被其他界面更新抢走焦点、长草稿输入卡顿的问题；排队消息会在后台正确派发，旧的排队运行和上下文压缩前的过程消息会收起，界面更简洁且减少无意义提醒。
- **长会话渲染性能提升** — 减少输入区、历史选择层、滚动定位和流式消息转发的重复渲染与扫描；会话内容较多、持续输出或频繁切换历史消息时更流畅。
- **定时任务调度更新校验** — 修复切换调度类型或更新时残留不兼容字段的问题，补齐空执行日、间隔默认值与时间窗口边界校验，避免任务保存后以错误配置运行。
- **Markdown 编辑与渲染修复** — 富文本差异编辑器会继续预览 Mermaid 图表，同时保留专用源码编辑方式；修复标签式加粗标记的渲染异常。
- **跨平台与界面细节修复** — 修复 Windows `Ctrl+B` 与侧边栏快捷键冲突、macOS Agent 灵动岛空闲展开时无法收起或关闭、浏览器文件面板折叠时出现多余提示等问题。
- **模型、技能与存储稳定性修复** — 修复 OpenCode Go Vision Relay 模型路由、Qwen/浏览器/自动更新相关回归，以及切换 Skills 时列表抖动；默认不再自动清理孤立数据，降低误删本地数据的风险。
