# Proma v0.19.53 更新

## 新功能

- **新增 Exa Search 接入** — 「连接」目录新增 Exa Search 卡片（排在 Brave Search 之后），填一个 API Key 就能接上 Exa 官方远程 MCP，获得语义网页搜索和页面内容提取能力；Key 会加密保存到系统 Keychain，Proma 会先完成真实握手与工具发现验证再启用。
- **DeepSeek Flash 支持 1M 上下文** — 上下文窗口按 1M 计算，界面展示和用量统计与实际能力保持一致。
- **DeepSeek V4.1 Flash 更名为 DeepSeek Flash** — 模型 ID 统一为 `deepseek-flash`，DeepSeek 渠道与火山引擎 Coding Plan 等预设模型、思考深度配置同步跟随新 ID。

## 依赖升级

- **Pi Agent SDK 0.85.0 → 0.85.1** — 五个 `@earendil-works/pi-*` 包统一升级，带来 `prompt_cache_options` TTL 修复以及 TUI 悬停、滚轮交互修复。
