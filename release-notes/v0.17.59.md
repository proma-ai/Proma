# Proma v0.17.59 更新

## 新功能

- **改动面板过滤 dotfile 目录变更** — 工作区改动面板在扫描 Git 变更与未跟踪文件时，过滤掉以点开头的目录（如 `.git`、`.idea` 等）及其内部文件，避免无关的 dotfile 目录变化刷屏，让面板更聚焦实际的代码改动。
- **改动面板展示记忆更新** — 在工作区 Git 改动列表底部新增记忆变更停靠区，协同 Agent 产出的 `memory/` 更新会单独汇总展示，与普通文件变更一起查看，不再混在文件列表里。

## Bug 修复

- **DeepSeek Flash Exp 视觉路由修复** — 补齐视觉中继的模型路由判断：DeepSeek Flash 实验视觉模型尚未进入 Pi 目录时，不再被 catalog 分流逻辑误判，直接按渠道协议走视觉中继，避免返回路径错误。
- **Agent 消息原子提交，避免瞬态失败** — 消息发送改为「判断活跃即注入、否则转入队列」的单一入口。Pi runtime 结束 query、渲染进程还没收到终态事件的窗口里注入会被拒绝，这类「会话未运行」的瞬时错误现在安全降级到队列，不再向用户暴露为发送失败。
- **首次使用引导到模型选择器** — 未选模型但已有可用模型时，提示文案与按钮改为引导打开模型选择器（而非直接进设置），新用户能更快开始对话；只有确实无可用模型时才引导去设置启用渠道。
- **停止时终止全部待恢复的运行** — 结束 Agent 时显式关闭旧的迭代器，确保同一会话不会残留多个运行时；同时旧运行的迟到错误不再向新运行泄漏终态，停止也能覆盖「正在启动」的窗口。
- **后台化后仍能持续刷流** — 为 Agent 流事件批处理增加定时器兜底。`requestAnimationFrame` 被后台节流暂停时，后台窗口仍能周期性收到可见增量，避免窗口转后台后流停滞。
- **消除冗余的工具同步提示** — 自定义工具配置变更时静默刷新工具列表，不再每次都弹出「Chat 工具已更新」提示；操作反馈由各设置入口负责，避免重复打扰。
