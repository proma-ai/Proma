# Proma v0.16.3 更新

## 新功能

- **文件面板回归双来源视图** — 会话文件与项目文件恢复为独立切换和搜索，避免不同来源混杂，并可分别管理附件。
- **Composer 交互回归并完善** — 恢复 `@` 文件、`&` 会话和 `～` 待办/日程的快捷引用；统一附件入口，支持在 macOS、Windows 和 Linux 上选择文件或文件夹。

## Bug 修复

- **计划窗口快捷关闭** — 使用 `Cmd/Ctrl + W` 可正确关闭独立计划窗口。

## 下载

- **macOS Apple Silicon** — `Proma-0.16.3-arm64.dmg`
- **macOS Intel** — `Proma-0.16.3.dmg`
- **Windows** — `Proma-Setup-0.16.3.exe`
