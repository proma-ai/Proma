# Proma v0.16.7 更新

## 新功能

- **xAI 订阅（Grok OAuth）渠道** — 新增 xAI 订阅的 OAuth 授权登录，可在渠道设置中直接授权 xAI 账号，接入 Grok 系列模型，Pi 运行时可用。
- **灵动岛收起态显示渠道额度** — Agent 灵动岛收起时直接展示当前活跃渠道的额度摘要；同时启用多个渠道时，标注其余渠道数量，无需展开即可掌握用量情况。
- **Windows Agent 灵动岛交互优化** — 优化 Windows 上灵动岛的展开 / 收起与点击交互，并恢复灵动岛的 Todo / 日程提醒展示。

## Bug 修复

- **Windows 剪贴板复制统一走主进程** — 修复 Windows 上代码块、Mermaid 图、消息等场景复制失败的问题：新增统一复制工具，优先经 Electron 主进程写入系统剪贴板，规避 renderer 剪贴板权限限制。
- **Windows 规划窗口操作修复** — 修复 Windows 独立规划窗口标题栏拖拽区域与窗口控制按钮重叠导致的交互异常，窗口拖拽与关闭操作恢复正常。
- **灵动岛已完成状态同步** — 修复"完成但未查看"的标记在会话打开后未正确清除的问题；已读确认只作用于活跃会话，避免误清状态。
