# Proma v0.16.9 更新

## 新功能

- **工作区 Skills 批量导入** — 在 Skills 管理页选择来源项目后，可一次勾选多个 Skill 导入当前工作区；导入结果通过 toast 汇总成功、跳过与失败项。重复 Skill 会按既有策略处理，导入过程采用临时目录与原子落盘，避免中途中断留下不完整文件。
- **Agent 会话文件变更可见** — 即使项目目录不是 Git 仓库，Agent 在会话中创建或编辑的文件也会显示在「改动」面板；可按本轮与更早轮次查看、打开预览或在文件夹中定位，不再遗漏 Git diff 之外的产物。
- **全新上手引导与 FAQ** — 首次启动页升级为沉浸式欢迎界面，并提供 Agent/Chat、项目、文件、Automation、Reference、Side Answer、Subagent 等完整操作引导；新增集中式 FAQ 页面、目录导航和全局 FAQ 弹窗，常见问题可随时查阅。

## Bug 修复

- **Markdown 编辑状态与滚动位置保留** — 修复保存、切换 Tab 或窗口重新聚焦后，Markdown 编辑器退出编辑态、草稿/光标位置丢失或滚动跳回顶部的问题；自动保存与手动保存会按文件串行处理，避免旧请求覆盖较新的草稿。
- **语音听写输出与取消竞态修复** — 听写开始时固定输出模式和目标输入框，录音期间修改设置不会把文本写到错误位置；修复取消、提交和迟到转写事件相互覆盖的问题。目标输入框已失效时会回退复制到剪贴板并如实提示，同时保留用户已编辑的听写预览。
- **输入框 Mention 误触发修复** — 输入或粘贴 URL、邮箱、文件路径、Markdown 标题、颜色值及 HTML 实体时，不再错误弹出 `@`、`/`、`#`、`&` 等引用菜单；正常的 Skill、MCP 与文件快捷引用仍可使用。
- **图片** `@` **引用支持点击预览** — 输入框内的图片文件引用现在可直接点击打开内置预览，并补充 `.ico` 图片格式识别。
- **Todo 描述保存状态准确显示** — 切换 Todo 后，前一条任务的「保存中…/已保存」提示不再错误显示在新打开的详情中。
- **Windows 设置窗口控制按钮恢复可用** — 修复设置页标题栏拖拽区域覆盖最小化、最大化与关闭按钮的问题，Windows 用户可正常恢复和调整窗口大小。
- **Agent 灵动岛跨平台行为优化** — macOS 仅在支持的 macOS 26 及以上版本启用灵动岛；Windows 增加独立拖拽手柄、避免操作按钮被误拖动，并正确保存位置和限制在可见工作区内。
- **Pi 自动重试提示降噪** — Pi 运行时前 5 次自动恢复不再反复打断界面；若持续失败，最终错误和后续重试状态仍会正常展示。
