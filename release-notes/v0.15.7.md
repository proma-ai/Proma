# Proma v0.15.7 更新

## 新功能

- **本地项目根目录** — 创建项目时可以直接选择本地文件夹；所选文件夹会成为项目根目录和 Agent 的默认工作目录，项目内所有会话均可直接读写。
- **更清晰的文件层级** — 文件面板统一展示会话文件与项目文件，并明确区分项目根目录、会话工作台和附加目录。

## 其他优化

- **本地项目配置隔离** — Skills、MCP、Proma 的 CLAUDE.md 与 Memory 仍由 Proma 工作区管理，不会自动导入本地项目的配置。
- **更安全的删除说明** — 删除 Proma 项目不会删除用户选择的本地项目根目录或原始附加文件。
