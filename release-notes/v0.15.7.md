# Proma v0.15.7 更新

## 新功能

- **会话星标** — Agent 会话列表支持星标标记，未星标的会话仅在悬停时显示标记入口。(#1232)

## Bug 修复

- **Pi 终端流中断恢复** — Pi Runtime 在终端流事件意外中断后可安全恢复，保留已生成的正文并显示恢复操作。(#1236)
- **Pi 委派会话直接运行** — Pi Runtime 创建的委派子会话会直接使用完整工具权限运行，避免 Plan 模式导致工具集不完整。(#1237)
- **修复 Mermaid 超宽图滚动** — 超宽 Mermaid 图表可正常查看左侧内容。(#1224)
- **修复 Qwen/Xiaomi Token Plan 标题生成** — 标题请求不再携带不兼容的 thinking 字段。(#1233)
- **修正 Codex OAuth 上下文窗口** — GPT-5.4 和 GPT-5.5 的上下文窗口正确识别为 272K。(#1231)
