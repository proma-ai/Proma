# Proma v0.16.8 更新

## 新功能

- **Proma 企业版：Skills 分发与协作** — 企业版新增 Skills 的组织级分发与团队协作能力：管理员可将团队沉淀的 Skills 一键下发到成员的 Proma，成员侧无需手动安装即可在 Agent 中直接触发使用；同时支持对 Skills 的版本、更新与使用范围进行统一管理，让组织内的最佳实践在规模化部署中保持一致。面向数百至数千人规模部署的组织，可通过企业版授权获取该能力。
- **Vision Relay：为纯文本 Pi 模型接入视觉能力** — 新增 Vision Relay 通道，把文本型 Pi 模型的图片请求中转给支持视觉的模型处理，让纯文本模型也能"看图"，并加固了文件访问、图像解码与上传链路，保证多种图片格式的稳定投递。
- **外部拖入文件接入** `@` **引用** — 从系统（Finder）拖入普通文件到 Agent 输入框时，不再显示为附件 chip，而是复制到会话私有工作目录后插入 `@file` 引用，Agent 可直接读取；超大文件、无项目或保存失败时自动回退原附件逻辑。同时修复引用路径含空格时的编码与展示问题，保证即时发送、排队消息、自动发送与重试全链路一致。
- **Todo 描述草稿式自动保存** — 描述输入停顿 800ms 自动保存、失焦立即保存，关闭详情面板（×/Esc/空白）时也会 flush 未保存的标题与描述，不再因误关丢失内容；描述标签旁新增「保存中…/✓ 已保存」状态提示，2 秒后自动消失，且自动保存不回写输入框、不打断输入。

## Bug 修复

- **Pi 上下文溢出恢复** — 修复 Pi 运行时上下文溢出后无法正常恢复的问题，溢出后可自动恢复继续对话。
- **64K 输出上限只对真正的 Claude 模型生效** — 修复因模型 ID 包含 `claude` 子串（如自定义 fork、`gateway/claude-proxy` 代理别名）而被误注入 `CLAUDE_CODE_MAX_OUTPUT_TOKENS=64000` 的问题；现在仅按真实 Claude 家族名判断，覆盖 `claude-sonnet-4-6` 与 `claude-3-5-sonnet-20241022` 两种命名形态。
- **Scratch Pad 底部编辑缓冲保留** — 修复 Scratch Pad 底部编辑缓冲在特定交互下被清空的问题，编辑内容不再意外丢失。
- **浅色主题选中文字前景色修复** — 修复浅色主题下选中文本前景色异常，文字选中后依然清晰可读。
- **Vision Relay 运行时打包修复** — 修复 Vision Relay 依赖的 `sharp` 运行时打包缺失，图片处理在生产包中可用。
- **OAuth 授权请求统一走应用代理** — 渠道 OAuth 授权请求改为经应用代理发起，授权流程在代理环境下更稳定。
- **macOS 26 前禁用灵动岛** — 在 macOS 26 兼容性就绪前暂时禁用 Agent 灵动岛，避免新系统上的异常表现。
